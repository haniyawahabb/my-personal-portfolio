- `style.css` — responsive premium beige/black theme, gradients and animations
- `script.js` — rain animation, scroll reveal, navbar behavior, project tilt and AI portfolio chatbot

- `assets/profile-2.jpg` — second provided profile image

## Chatbot
The chatbot is a client-side portfolio assistant. It answers from Haniya's supplied portfolio information and uses the browser Speech Synthesis API for voice replies. No API key is required.

## Run
Open `index.html` in a browser, or use VS Code Live Server for the best local development experience.
